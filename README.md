# ACJ Portals

Public portal hub for ACJ property management.

## Portals

- **Montgomery Place - BM Portal** - Property management dashboard for Montgomery Place

## Hosting

This site is hosted on **GitHub Pages** and automatically deploys when changes are pushed to the `main` branch.

**Live Site:** https://axel675.github.io/acj-portals/

## Adding New Portals

1. Add your HTML file to this repository
2. Add a link in `index.html` pointing to your file
3. Push to `main` branch
4. The site will automatically deploy within seconds

## Development

To test locally:
```bash
# Simple HTTP server
python -m http.server 8000
# or
npx http-server
```

Then visit `http://localhost:8000`
